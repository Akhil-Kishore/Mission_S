# Mission S

This repository contains a minimal full-stack web application scaffold.

## Stack

- **Frontend:** React with Webpack and Babel (see `client/`)
- **Backend:** Node.js with Express and PostgreSQL (see `server/`)
- **Database:** PostgreSQL
- **Tooling:** ESLint, Prettier, Docker, and GitHub Actions CI

## Development

Install dependencies and run linters:

```bash
npm install
npm run lint
```

Start services with Docker:

```bash
docker-compose up
```
